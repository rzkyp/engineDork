## Tentang

Kumpulan query Google Dorking dan helper Python untuk menemukan aset/informasi sensitif yang terekspos.

## Syarat

```bash
pip install -r requirements.txt
```

## Pakai

Jalankan `enginedork(Decrypt).py` dan pilih/gunakan query sesuai kebutuhan.

## Disklaimer

Hanya untuk pengujian pada aset sendiri atau yang berizin. Google Dorking pada sistem orang lain tanpa izin melanggar hukum.
